# CityLab - Product Overview

## Project Purpose
CityLab is a cyber range for ICS/SCADA systems that simulates offensive/defensive operations in cyber-physical environments and critical infrastructure. It provides a 100% software-based simulation platform that runs natively on Linux with low RAM consumption (<1 GB).

## Value Proposition
- **Realistic ICS/SCADA Simulation**: Emulates industrial control systems, physical processes, and network segmentation
- **Multi-Sector Co-Simulation**: Integrates water, gas, and electrical infrastructure simulations
- **Cybersecurity Training**: Enables red team/blue team exercises for critical infrastructure protection
- **Research Platform**: Supports academic and industrial research on cascading failures and cyber-physical attacks

## Key Features
- **Network Emulation**: Mininet-based network topology with IEC 62443 segmentation
- **Physical Simulation**: ICSSIM-based water, gas, and electrical system simulations
- **Control Systems**: Modbus PLC emulation with ST (Structured Text) programming
- **Co-Simulation**: HELICS federation for multi-domain simulation synchronization
- **Attack Framework**: Modbus attack scripts for penetration testing
- **GridLAB-D Integration**: Electrical substation modeling and simulation
- **Centralized Logging**: Real-time monitoring of cascading failure events

## Target Users
1. **Cybersecurity Professionals**: Red/blue teams training on ICS/SCADA security
2. **Academic Researchers**: Studying cyber-physical systems and cascading failures
3. **Industrial Engineers**: Testing control system configurations and security measures
4. **Government Agencies**: Critical infrastructure protection and resilience testing

## Use Cases
- **Penetration Testing**: Simulated attacks on industrial control systems
- **Defense Training**: Blue team exercises for incident response in OT environments
- **Research Experiments**: Studying cross-sector cascading failures
- **Educational Labs**: Hands-on training for ICS/SCADA cybersecurity
- **System Validation**: Testing control system configurations and network segmentation

## Capabilities
- **Network Segmentation**: Corporate, DMZ, and OT cell zones with firewall rules
- **Multi-Sector Simulation**: Water treatment, gas distribution, and electrical grid
- **Real-time Monitoring**: Centralized CSV logging of system states and events
- **Interactive Operation**: Mininet CLI for network manipulation and attack execution
- **Headless Mode**: Detached execution for automated testing and research
